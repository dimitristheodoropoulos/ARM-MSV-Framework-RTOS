# v2.5 Release Verification

## 1. Scope

This document defines the verification evidence for the
**v2.5 Production Baseline** of the ARM MSV Framework RTOS.

The release baseline focuses on:

- reproducible ARM Cortex-M3 firmware builds
- target ELF validation
- QEMU-based system integration testing
- CLI functional verification
- TinyML inference verification
- CI build and test enforcement
- repository hygiene

No new functional features are introduced as part of this release gate.

---

## 2. Target and Toolchain

The firmware targets an **ARM Cortex-M3** processor using the
**LM3S6965** platform model.

The production build uses:

- `arm-none-eabi-gcc`
- GNU Make
- ARM Thumb instruction set
- FreeRTOS
- QEMU Cortex-M3 emulation
- Python 3 / pytest for integration verification
- GitHub Actions for CI

The firmware is built with:

```text
-mcpu=cortex-m3
-mthumb
-msoft-float
-ffreestanding
```

## 7. Continuous Integration

GitHub Actions performs the production verification workflow on both
pushes and pull requests.

The CI pipeline performs:

1. Repository checkout
2. ARM toolchain installation
3. QEMU installation
4. Python 3.12 setup
5. pytest installation
6. Clean firmware build
7. Firmware ELF verification
8. QEMU integration tests

The CI test command is:

```bash
pytest -q
```

The firmware build is verified with:

```bash
make clean
make
```

The generated ELF is additionally checked with:

```bash
test -f firmware.elf
arm-none-eabi-size firmware.elf
```

Result:

**PASS — CI workflow implemented and locally aligned with the
production verification flow.**
