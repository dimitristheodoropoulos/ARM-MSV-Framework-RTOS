# v2.6 Runtime Verification

## 1. Scope

This document records the runtime verification evidence for the
**v2.6 production baseline** of the ARM MSV Framework RTOS.

The verification combines:

- clean firmware rebuild
- QEMU ARM Cortex-M3 emulation
- FreeRTOS runtime observability
- CLI-based functional verification
- TinyML inference execution
- watchdog recovery testing
- HardFault recovery testing
- automated pytest integration testing

The manual QEMU tests provide runtime evidence independently from the
automated pytest regression suite.

---

## 13. Verification Conclusion

The v2.6 runtime verification demonstrates that the ARM MSV Framework
RTOS executes successfully under QEMU on the LM3S6965 Cortex-M3 target.

The verification covers normal RTOS operation, runtime observability,
TinyML execution, and deliberate fault/recovery scenarios.

Combined with the automated **17/17 pytest regression result**, the
current evidence supports the **v2.6 production baseline** for the
verified QEMU runtime environment.

The verification does not claim physical-board behavior where it has not
been independently validated.
